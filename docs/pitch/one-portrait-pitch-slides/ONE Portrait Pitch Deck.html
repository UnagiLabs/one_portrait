Why Sui × Walrus

ONLY THIS STACK
WORKS.

No other stack pulls this off. この組み合わせでしか成立しない。

// STORAGE
Walrus Persistence
Walrus で永続保存。
Final mosaic and target images live on decentralized storage; `blob_id` is the canonical identifier.
// LOOKUP
Sui Table Reverse-Lookup
Sui Table で blob→座標を逆引き。
`placements: Table<blob_id, Placement>` resolves coordinates on-chain at near-zero cost.
// SOULBOUND
Type-Level Guarantee
型レベルで譲渡不能を保証。
`key only`, no `store`. Non-transfer is enforced by the type system, not by a runtime check.
// UX
zkLogin + Sponsored Tx
Google 認証＋スポンサード送金。
Google sign-in only. Zero gas for fans — Enoki covers every tx.
